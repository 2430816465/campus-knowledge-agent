## 如何查看

各项目 README 提供代码入口与运行条件。`VALIDATION.md` 记录本次源码检查和历史实测，帮助复核检索指标、工程逻辑与产品完成度。

密钥、真实聊天、数据库、模型权重、个人部署配置和构建缓存未发布。游戏合集采用源码审阅版，许可尚未核实的运行素材未收录。各项目和第三方文件保留自身许可，仓库没有统一授予全部内容 MIT 许可。
