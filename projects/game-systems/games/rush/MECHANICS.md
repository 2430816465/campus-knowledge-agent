# 箱子、属性光幕与符法 · 2026-10-02

用户要求：删除门下的“剩几人”，略增第一关难度，大幅增加第二关难度但仍低于第三关；增加奖励箱、减员箱、大量队友与新武器，每三关引入新机制，并增加射速、射程、伤害门。

事实：当前是御剑学徒 C、十八关独立路线、局外三项轻量训练。推理：删人数预览会增加计算压力，奖励箱必须在小队减员后仍能击破，危险箱必须可辨认、可避让。风险：自动射击容易误引爆危险箱；满编符弹容易遮住小角色。本轮用红箱标记、可见保护、独立安全路线、小符弹与绘制层次处理这些问题。

## 规则与边界

- 门仅显示运算或属性名称/百分比，所有版本均删除人数预览。算术门按队伍中心选一路，加减乘除、向下取整、归零失败不变。通过后显示短暂结算反馈，门不再重复生效。
- 属性每种最多三层：射速 +60%、射程 +60%、伤害 +75%。射速与局外训练相乘，伤害与训练/剑诀相乘。三种属性独立叠加，只在本局生效，HUD显示当前增益。
- 新版基础飞行射程450逻辑像素，射程门每层增加90，最多720；按每个弹体的实际累计飞行距离销毁，召出过程不计入射程。最早两个版本保留原来的不限飞行距离。
- 新版奖励箱击破立即给予剑诀、队员或新武器，不再要求接触箱子。未击破直接碰到会错过奖励。危险箱击破或碰撞都会扣其标注人数，至多触发一次；人数不足可直接失败。
- 红箱在顶部80像素内不受弹体伤害，且耐久高于奖励箱，防止刚露头就被自动射击引爆。换边可以完全避开。没有随机隐藏惩罚，爆裂量始终可见。
- 飞剑二次强化保留一次穿透。雷符单枚直线飞行，命中连锁95像素内最近两个魔物，额外伤害为直接伤害的45%；炎符命中后伤害60像素内其它魔物，额外伤害为55%。符法不连锁、不溅射箱子，直接瞄到红箱仍会造成伤害。符弹不穿透、不无限递归触发。
- 每名队员仍从身侧召出弹体、错开施法，0.12秒后沿对应列飞行。符弹缩小至箱子图标的约四成，画在队员之前；角色与门字在弹幕前方。保留原始像素角色/剑图集，弹体上限240、效果上限180。
