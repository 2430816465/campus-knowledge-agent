# 再冲一阵 · 御剑小队

营地第十入口。左右拖动或 A/D、方向键移动，自动御剑；保留数字门选路、闯关和轻量成长。三章十八关，主线依次解锁，已过关可以重玩。十八关已分别编排木桥、矿轨、钟庭、牢狱等路线，敌阵、石阵、补给与光幕顺序各不相同；[逐关设计与验证记录](LAYOUTS.md)。

光幕支持加减乘除，包括减法/除法同时出现的二选一；除法向下取整，门只显示运算，不再显示剩余人数，归零即失败。符文门按小队中心所在侧结算，人数最高48。标注射击的门每中五剑增加一人、最高+12。新版金色剑匣和蓝色伙伴箱击破立即生效；大量伙伴箱可增加8—20人。红色爆裂箱击破或接触都减员，需避开。石块阻挡飞剑并碰撞实际队员。消灭首领才通关；队员耗尽或漏过首领失败，可免费重试。

第3关起启用破阵目标：正确门带金色「◆ 破阵」符印，另一侧仍结算效果但计一次失误。3–6关可错3次，7–12关2次，13–17关1次，18关必须零失误；每关重置，障碍损失不计。每次错门使首领抗性增加8%，超限封印无法解除。所有门通过后首领才可被攻击；容错内仍需保住小队与击破补给。详见[数值与验证记录](BALANCE.md)。

符晶用于淬剑、御剑速度和开局队员，训练有等级上限。本地首通奖励32+关卡×3符晶，重复胜利10，失败根据击破数最高8。营地每关首通8冒险币，按关卡固定回执去重。暂停、离开、切后台会保存完整战场；未完成的旧局保留原路线，新开局使用 layoutVersion 4 的破阵容错与首领数值；版本3使用冻结的 layout-v3.js，版本2使用 layout-v2.js，最早版本使用 legacyPlan。

用户选择C「御剑学徒」。米白短衣、深色束发、红发带，角色朝上结印。飞剑从每名队员身侧召出，0.12秒升起后沿对应列向前飞行，各列与各排错开释放。剑诀升级增加伤害，二次强化获得穿透；短青色拖尾控制画面占用。剑身碰撞覆盖实际剑宽与剑尖。

角色主体约17–24×32逻辑像素，队列横向间距26、纵向34。角色/剑分别使用四帧图集；最近邻导出、硬透明边缘、Canvas关闭平滑缩放、CSS pixelated。48人时底排脚部仍在战场内，队长用金色脚下标记区分。小队人数与剑诀等级放在上方HUD，避免文字遮挡底排。

素材由内置 image_gen 生成；原始图、提示词和图集在 assets/apprentice、assets/flying-sword。[来源与处理参数](assets/art-manifest.json)，[导出检查](assets/pixel-export-qc.json)。角色与飞剑以现有营地素材的轮廓、配色为参考，没有复用参考小游戏的角色或素材。
