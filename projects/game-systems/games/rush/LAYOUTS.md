# 再冲一阵 · 十八关独立路线

用户要求：保留闯关与轻量成长，继续使用已选的 C 御剑学徒；降低关卡重复，增加减法、除法及双减员二选一，难度随进程提高。

原来所有关卡使用同一组四道门、四次波次和两个补给时间。新版在 `data.js` 的 BLUEPRINTS 中分别编排每一关的门、分界、摆动、敌阵、石块和补给位置；不是只修改生命与数量。十八种地面/路边组合与关名对应。背景图案不参与碰撞，真正的石块仍有实体、挡剑和接触减员。

## 算术与选路

- `+n` 加人、`−n` 减人、`×n` 乘人数、`÷n` 除人数并向下取整，最终范围为 0—48；0 人立即失败。
- 根据队伍中心通过其中一道门，成员跨过分界不会领取另一道门；存档恢复也不重复结算。
- 门上仅显示运算，需要根据 HUD 当前人数自行比较。如 `÷2 / −3`：4 人时除法留下 2 人、减法留下 1 人；10 人时除法留下 5 人、减法留下 7 人。两边同时减员并不存在永久更优的一边。
- 除法门为紫色，减员门为红褐色，增员门为绿色；归零风险继续用深红色区分；已通过的门淡出，不显示人数预览。
- 标注“射击提高人数”的加法门仍可每中五剑提升 1，上限 +12。双减员门不靠射击改成增员门。
- 新版门从进入屏幕到到达队伍至少有五秒以上的可见接近时间；偏置分界与摆动范围限制在可选路区域。

## 难度与成长

行进速度由第 1 关 92 提高到第 18 关 107.3 逻辑像素/秒；普通敌人生命随关号提高，后期增加敌阵密度、法师、横移、移动门与连续减员。每章第六关是首领压力峰值，下一章先介绍新布局，因此并不宣称每一项数值都严格超过上一关。

重要节奏：后期连算前提前出现第一只剑匣，减员后保留补员窗口；双塔关的压力放在法师与后半敌阵，避免早期减员和夹击重合产生瞬间归零。三个章末首领生命分别为 360 / 550 / 760，后期法球有 0.65 秒施法提示；增长压力来自人数损失与路线，不能只比较旧版首领生命。

三条训练、符晶收入、首通/重玩奖励与营地去重规则不变；无需追加新货币。旧保存键仍为 `camp-rush-v1`。旧活动战斗没有 layoutVersion，继续使用 legacyPlan 和原速度；layoutVersion 2 继续使用冻结的 layout-v2.js。下一次新开局才使用 layoutVersion 3；已通关、成长、货币和已领取奖励保持原值。

- `node tools/rush-layout-audit.mjs`：0.25 / 0.5 / 0.75 秒一次的固定自动路线，仅消费真实初始及首通所得，均连续通过 18 关；详细收入/消费/人数/剑诀在 `artifacts/rush/layouts/campaign.json`。没有强制胜利、修改生命或额外发币。属于模拟策略，不是玩家数据。
- `node tests/rush-layout-browser.mjs`：18 关真实运行截图、320/390 像素无人数预览的算术门显示、左右选择、归零失败与重载不重复结算。
- 原 browser 测试覆盖键盘/触控、首末关胜负、暂停、重载、训练、四种视口与第十入口回执。sword-browser 保留五组视口/DPR 的满编检查及营地菜单续玩。
- 人的操作压力、长期留存与实体手机性能尚未测量；网页源码已更新，不包含新的 APK 构建。

2026-10-02 的箱子、属性门、符法与前三关难度调整见 [MECHANICS.md](MECHANICS.md)，此表记录各关路线骨架，实际事件以 data.js 为准。
