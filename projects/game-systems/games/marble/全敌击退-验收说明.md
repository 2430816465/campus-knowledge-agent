# 再弹一次 · 全敌击退（2026-10-01）

## 已实现

- 每局2次免费击退，用完后开放可选广告击退，每局最多2次。
- 入口位于右上角设置面板上部，显示免费与广告剩余次数；使用成功自动收起面板，回到瞄准。
- 所有存活游魂和 Boss 的纵向位置向地图顶部退回一半。例如 y=300 推回至150；再次使用至75。顶部保留角色半径加4的边界，不推到屏幕外。横向位置不变。
- 只在瞄准阶段使用；飞行、下沉、选卡、失败、结算和暂停时禁用。没有可退回的敌人时禁用，不扣次数。
- 生命、经验、击杀、发射次数、Boss 生命／护甲／行动倒计时保持。障碍不移动，冻结状态保留。
- 击退不占用“冻结／额外能力二选一”的一次战术帮助。广告两次仅指本功能，不限制其它已有广告入口。
- 免费及广告次数随本局存档保存；读档或恢复中断齐射不会补回。旧无尽局加载后补上该功能的初始额度，新局重置。
- 广告回调绑定本局ID及本次使用序号，重复或过期回调不能重复领取。提前关闭、取消及观看前刷新不扣次数。沿用现有开发模拟：加载／展示失败兜底领取一次，并计入两次广告额度，记录为fallback。
- 添加向上的像素冲击波与短促上扬音效。修复桌面独立版缺少样式标记导致按钮触摸尺寸过小的问题。

## 事实、推理与边界

此前玩法没有这项击退功能。新增四次整体救场会延长生存时间，且敌人压缩到上半场后更利于范围伤害，这是本轮明确增加的收益。使用次数有限，后续出怪、下沉及Boss成长继续按现有曲线执行。本轮没有重新提高敌人数值抵消救场。

“向后50%”采用当前位置向地图顶部减半的明确规则，未采用整张地图固定高度的一半。广告仍是当前工程已有的开发模拟，尚未接入正式平台SDK。
