# 无尽模式更新验收 · 2026-10-02

## 改动

- 弹珠增幅仅有史诗、传说两档，分别增加 1、2 颗主弹珠；第一次击杀领主后才进入随机候选。初始仍为 1 颗，上限 8 颗。免费重选、额外选卡同样遵循解锁和品质限制。旧存档保留实际弹珠数量，迁移为新的数量单位。
- 领主在第 15、30、44、57、69、80、90、100……发结束后出现。最短间隔由 5 发放缓到 10 发。下一位独立按发射计数，旧领主存活、死亡、越线、冻结、击退都不会推迟计数。旧存档恢复时按当前发数安排下一次出场，不集中补刷历史欠缺领主。
- 四种领主轮换：黑甲领主、符岩巨像、暮影法师、翡翠翼龙。复用工程内现有透明像素角色素材，统一显示尺寸和 23 单位碰撞半径；形象不额外改变生命或行动机制。
- 帮助页改为独立滚动：标题和页签固定，帮助内容和按钮保持自然高度，超出小横屏的部分可滚动查看，不再溢出面板。关闭面板后恢复完整战场。
- 广告结束统一清理忙碌状态和遮罩，将焦点暂停与营地明确暂停分开。冻结、额外选卡、广告击退结束后收起设置；营地手动暂停仍保留。取消或失败不发奖励、不扣游戏帮助次数。
- 公共模拟广告处理完成、提前取消、原生关闭、节点被移除、展示异常等情况，释放预约并恢复子游戏焦点。
- 小店关闭广告窗口后恢复经营；合作模式异常或结算切换时释放按钮锁定，不把奖励发送到另一个结算。

## 验证

- 228 项 Node 回归测试通过，包括旧存档、稀有度限制、独立领主计数、额外弹珠上限、群伤额度、冻结和击退。
- 浏览器：冻结、额外选卡、广告击退完整流程；取消、加载失败、展示异常；营地显式暂停期间完成广告；完成后真实拖动发射，飞行计时继续。
- 公共广告：塔与合作子页面关闭/移除广告窗口，焦点与预约恢复。合作模式联机结算尚未做多设备实测。
- 小店：取消、原生关闭、完成后经营时间继续；吞噬：取消、失败不消耗复活，完成后可实际移动。
- 帮助页与领主外观：568×320、667×375、844×390、1024×768，底部帮助按钮可滚动进入面板并点击，标题不移动；浏览器无脚本异常。
- 数值模拟采用固定简单瞄准策略、6 个种子：全普通天赋配合免费击退和有次数/冷却限制的帮助，结束于 63–72 发；随机天赋配合帮助，75–85 发；不使用帮助的随机组，38–88 发。它们是程序模拟结果，不是真实玩家生存率；不保证任意瞄准或选择都能到后期。

## 验收重点

1. 在横屏打开“能力与设置 → 帮助”，滑动到最下面，检查冻结和额外选卡能否完整显示、点击。
2. 完成一次模拟广告后直接瞄准发射，不需要额外点击空白处“解卡”。
3. 首位领主击败前不出现弹珠增幅；之后只在紫、金卡出现，文字和实际弹珠数量一致。
4. 第 15、30、44 发后观察领主出场；故意保留上一位，下一位仍按独立计数出现。新局按四种外观循环。

工程已同步到桌面合集和桌面《再弹一次》。本轮未更新 APK。广告仍为当前工程的开发模拟提供器，尚未在真实广告 SDK 和 Android 真机上验证。
