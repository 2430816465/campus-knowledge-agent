# 勇者棋牌

合集中的棋牌入口，三人斗地主、四人斗地主、掼蛋、南京麻将。四位原创勇者可选择，人机练习无需网络。房间支持准备、邀请、机器人补位、托管、同座重连、逐局结算与下一局。棋牌分数不兑换营地冒险币。

## 启动与联机

项目根目录 `node server.mjs`，打开 `http://127.0.0.1:4173/`，进入勇者棋牌。电脑房主与朋友打开同一局域网地址，例如 `http://电脑IP:4173/`；选择同一玩法，房主创建房间，朋友用6位房号加入，所有真人准备后由房主开局。也可以在联机设置里填写电脑的内网IP。

Android原生 `CampLan` 桥接复用《再骗一杯》的手机服务：手机房主创建桌，朋友在“联机设置”填写房主IP，再加入房号。房主需保持前台，手机切后台或退出会关闭本机服务；房主服务关闭时无法依靠重连凭证恢复服务器状态。普通掉线由机器人立即代打，30秒内自动重连回原座位；30秒后席位转为机器人。纯浏览器手机可连接电脑房主，也可本机练习。

快速匹配在**同一Node服务器**内按玩法凑桌，8秒后用机器人补位，采用默认规则。手机局域网请用好友房。联网过程中退出菜单不暂停其他玩家。离席由机器人接替，房主转交给在线真人；全部真人离开则销毁房间。

## 规则选择

“最大众”无法用公开资料验证为唯一版本。采用可核查的常用运营规则，房间展示实际口径：斗地主使用JJ公开牌型；掼蛋双下/三游/末游升3/2/1级、红桃级牌配牌、同花顺大于5炸小于6炸、进贡/还贡/抗贡/接风；南京麻将144张（中发白与季节梅兰作花）、碰杠不吃、门一跑一、花砸2，选项和逐项结算可查看游戏内“规则”。南京麻将未宣称与腾讯逐条相同。

南京房可设2/3/4人、4/8局、不封顶/300/600、门一跑一/门二跑二，开关花砸2、兜翻底、海底捞月、双七对、一炮多响、比下胡、包牌包三家、直杠/补杠算门清。2/3人沿用完整144张牌，包牌按实际人数减一份。硬软花加2、无花果30、碰碰胡30、混一色30、清一色40、七对50、双七对100、风一色100等具体值以游戏内规则为准。

资料之间存在差异：兜翻底使用本房明示约定“杠后自摸总花×2”；关闭改为+40花。海底为余墙≤4张时自摸+20花，采用打完牌墙流局；不实现留8墩、进园子扣底与整铲、快照自动第四碰、真实货币或微信好友账号。底花、门清、软硬花、番型、翻倍和封顶均在结算展开显示。

## 公网部署

**目前没有已部署的公网服务器**。可部署代码和HTTPS连接入口已完成，购买/选择托管后才可以跨城市连接。房间和重连凭证只在进程内存，服务重启清桌；托管应开启常驻运行，避免自动休眠。服务器/域名/TLS的托管费用尚未确定，没有创建收费服务。

参考根目录 `Dockerfile.chess`、`compose.chess.yml` 和 `Caddyfile.chess`。准备域名A记录到服务器，开放80/443，把Caddyfile的 `cards.example.com` 替换为域名，运行 `docker compose -f compose.chess.yml up -d --build`。Caddy签发证书并代理WebSocket。客户端在“联机设置”选择互联网，填 `https://你的域名`；Android打包默认地址可填写 `games/chess/server-config.json` 的 `serverUrl`。默认允许Android资源来源 `http://127.0.0.1:38473` 和同源网页；跨域网页需在环境变量 `CHESS_ALLOWED_ORIGINS` 明确列出完整来源（逗号分隔），不可盲目允许任意来源。

此服务用于好友房，不含公网账号、跨设备身份恢复、管理后台、数据库、持久战绩。最多128连接/100房，单消息16KiB、输入缓存32KiB、待写128KiB，每人每秒30命令，房间2小时到期。LAN房主能查看本机权威状态；互联网部署方能查看服务器状态。这不是针对作弊服务运营商的加密防作弊方案。

## 验证

`node --test tests/chess.test.mjs tests/chess-ux.test.mjs`：物理牌数、四人33张、牌型大小、配牌约束、七对与封顶、多响、80局随机整局、连续掼蛋进贡、收支守恒、私有快照、重连、动作去重与过期拒绝。

`BASE_URL`指向当前服务，运行 `node tests/chess-browser.mjs`：独立4浏览器整局、延迟150ms/重复40ms、座位重连、手机布局/选牌、营地入口；截图在 `artifacts/chess-ux/regression`。Android桥接另见 `tests/chess-phone.mjs`。本轮未进行实体手机安装、触控和后台切换验收，也未重新生成APK。

公网容器/TLS模板按照[Caddy官方反向代理指南](https://caddyserver.com/docs/quick-starts/reverse-proxy)准备。本机没有执行Docker构建或公网证书申请，因此未将模板测试描述为实际部署成功。

手牌改为居中的单排连续叠牌，四人地主33张在568×320仍完整呈现；点按/滑动时放大当前牌，滑动可增加或撤回连选，双击选同点数。重新绘制原创SVG扑克花色、点数、大小王、万条筒和字牌。选牌仅更新手牌状态，不重建整个牌桌；提示循环给出合法方案，按牌型理牌不改变牌的归属。人物/比分/余牌/计时/出牌区固定位置，托管收进底部工具栏，长牌组按点数成组显示，点击可查看原始完整公开牌面。

出牌请求待确认时保留手牌和选择，拒绝/断线仍保留；重连立即锁定操作，新快照恢复。提示音区分选牌/出牌/叫分/不出/警报/轮到你/胜负；牌型动效不阻塞输入，支持关闭动效/系统减少动态效果。中文语音与震动默认关闭，依赖设备。公开记牌扣除自己的牌与已出牌，不使用对手暗牌；剩余手牌只在结束后公开。
