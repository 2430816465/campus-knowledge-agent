# 魔王面包房 · 像素厨房与主题经营（当前最新待整合）

2026-10-03，基于 1.26.0。权威源码为桌面 `总/adventure-camp`。不生成 APK，不调整发布版本，不同步 Android assets。

## 场景与操作

采用用户选择的第 1 张参考图：正交俯视、暖色像素、连续外围柜体与中央工作岛。四区使用独立地面与后墙，采用分层可交互家具，不把玩法烘焙在整张背景里。

- 原料区：左麦田、中奶牛棚、右莓果种植床、前方原料仓；木石围栏和边缘种植陈设围合。
- 烘焙区：后方双炉、左磨坊、右果酱锅、中间工作岛；围绕家具通行。
- 门店区：左订单柜台、后展示架、右餐桌、中间备餐台；橱窗与木地板。
- 外卖区：左打包台、右马车、后仓库货架、中间整理台；装卸石地与仓库门。

场景采用固定正交镜头下的独立封闭实体网格，各家具拥有顶面、侧面和深度；将参考像素画投影到对应网格，保留纹理细节。不是任意旋转视角的精细雕刻模型。人物使用侧面、正面和背面各四帧透明精灵，左右共用侧面镜像，按真实深度遮挡，不再使用穿透桌面的半透明人物副本。

中央桌台、作物和货架按可见轮廓额外避让，脚底锚点落在地面，配地面阴影。导航区域比物理占地保守，以确保固定镜头下双脚不落到桌面图案中；代价是部分路线稍长，全部工位仍可到达。原料仓从右侧操作，展示架从上方通道操作。

去掉工位悬浮文字、描述和底部说明，可用建筑以金色提亮和带深色衬边的亮色四角标记，选中时角标加粗并轻微呼吸；已解锁但未建造的设施用浅蓝角标与加号提示建设入口，未解锁建筑不冒充可用状态。保留金币、菜单、分区和必要操作按钮；可访问名称仍保留，订单与配方的必要信息放在弹窗里。超宽屏侧边补木质纹理。

横屏玩法；竖屏暂停并提示旋转。点工位走近，原料按住采集，其余操作点击一次。烤箱、磨坊、果酱锅、打包与运输只处理已提交的一批。成品必须亲取、订单必须到柜台交付、配送必须亲自签收；升级与离线均不能自动赚钱。

## 主线、事件与数值

六队小单数量为 **1 / 3 / 4 / 5 / 6 / 7**，累计 26 张；单张仍为 2–6 个面包。首单维持三个普通面包、90 金币。三张可选普通订单不限时；自愿加急单仍为 150 秒、额外 40%，过期只去掉加成。

订单簿或菜单打开“主题活动手册”，逐步开放六个一次性主题：骑士早餐周、森林野餐会、法师下午茶、远足补给站、四味品鉴会、王国面包节。各主题组合不同配方、加工、堂食、订单和外卖目标；不倒计时。可随时切换，保留各主题已完成的操作进度。只记录当前主题下新发生的主动取货/服务，库存搬来搬去不能刷进度。

主题奖励依次为 180 / 260 / 340 / 420 / 500 / 680 金币及纪念章。到门店柜台领取，只能领一次。每两枚章增加烤箱最大批量 1，总上限仍为 6。新店最终目标包含六主题、六队、所有基础设施、传送带、送餐 8 份和签收 3 趟；主题过程已覆盖这些服务目标。已通关的旧存档保留通关状态，可继续体验新主题。

堂食客人有轮换口味偏好，符合时额外 +20%；其他口味仍正常销售。当前偏好在堂食操作详情中展示，无扣款、离店或强制等待。主动版的四种面包基础价值调整为 **22 / 38 / 64 / 78**，缩小旧版 12 / 32 / 80 / 100 的高阶收益差距；仅在 active-state 中覆盖，旧模块与其他游戏不受影响。设施价格与用途不变，购买提高主动操作效率。
