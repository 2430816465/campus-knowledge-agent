# 再骗一杯

第五营地入口，2—4 人经典诈唬牌局与六杯魔药淘汰机制。角色、卡牌与酒馆为原创 2D 像素美术。

每桌四个席位使用互不重复的角色。先保留不同的玩家选择，重复选择的席位分配剩余角色；机器人遵守相同约束。所有界面使用流浪勇者、余烬魔王、地精商人、暮影盗贼这四个角色名，取消昵称输入。出牌前可核对实际选中的牌，开牌时明确显示质疑者／出牌者与逐张真假，规则面板可查看最近开牌记录。每个角色各有六帧开牌和六帧喝药动作，在实际座位播放；开牌箭头连接质疑者与被开的牌，喝药结束才显示安全或石化。

牌局横屏铺满屏幕，采用暖色像素酒馆、中央椭圆牌桌和四角围桌人物。营地工具栏和游戏标题／连接状态条不占游戏画面。四个固定座位带唯一角色名和颜色；每人的出牌只留在自己面前，只有最新一手可被质疑，开牌保留原地牌堆，同时在桌中央放大最新一手并标红假牌。倒计时仅显示在当前行动者面前。每小局开始中央提示桌牌；手牌和出牌／质疑按钮集中在底部，开牌和喝药提示替换手牌区域，整局结算在居中面板显示。喝药、石化及安全药效果直接在被罚角色身上播放。规则、快捷语、声音和离席收入右上角菜单。手机竖屏显示旋转提示，浏览器全屏／锁方向失败时可手动旋转；联机计时继续。Android 使用现有 CampOrientation 桥进入横屏、离席恢复。

从根目录启动 `node server.mjs`，通过营地第五入口进入，或访问 `/games/liars/index.html`。浏览器好友须使用相同服务器地址和六位房间码。

- `rules.js`：纯规则与针对每个座位的私密快照。
- `rooms.js`：房间、动作权限、重连、时钟与随机数依赖注入。
- `server.mjs`：电脑 `/liars-ws?v=1` WebSocket 接入。
- `phone-worker.js`、`network.js`：现有安卓 `CampLan` 原生桥与手机权威 Worker。
- `game.js`、`render.js`、`style.css`、`table.css`、`actions.css`：输入、营地结算、界面、2D 绘制、围桌响应布局与动作指向。
- `animations.js`、`assets/animations/`：角色各十二帧、服务器时间选帧、动作身份与资源预加载。
- `feedback.js`：服务器时间驱动的动作阶段、合成音效、振动与衰减晃动；可关闭。
- `presentation.js`：角色名投影、公开牌堆的座位归属、最新一手翻牌与固定轮次提示。
- `assets/prompts.json`：最终像素素材生成提示词与处理记录。
- `assets/remake-prompts.json`：围桌重制背景提示词、参考来源与信息边界。

快速匹配使用共享 FIFO 队列，等待最多 8 秒补足四席；`bots.js` 的策略只接收自己的私牌与公开信息，`matchmaker.js` 负责组桌。机器人内部随机 ID 保留；按用户最新要求，与真人一样只显示角色名，统一快捷语不带身份标签。

`match-config.json` 中的 `serverUrl` 留空时，浏览器匹配同一营地服务器的玩家；Android 使用本地 Worker 测试桌。未来公共服务器设置 HTTPS 根地址，使用 `/liars-ws?v=1`，跨域入口通过 `LIARS_ALLOWED_ORIGINS` 精确配置。服务器动态战绩存入根目录 `.liars-data/records.json`，该目录不对静态访问开放。

详细规则、验证与交付边界见根目录 `第五玩法-再骗一杯.md`、`牌局匹配与机器人.md`、`牌局动作与判定修订.md`、`牌桌画面重制-20261001.md` 和 `角色名与完整动作-20261001.md`。当前未部署公共服务，不支持语音或房主迁移。只有本地币存档；本次源码修订未重新打包 APK。

机器人每手出牌随机等待：90%为3—8秒，10%为8—12秒。质疑判定展示结束后，服务器直接进入自动喝药，取消选择、按钮和额外等待；完整喝药动作1.8秒，随后显示安全药效果或石化。出牌者与新牌堆同步高亮、移动并播放音效；轮到本人的提示与最后5秒提醒带音效及可关闭的震动。各座位的倒计时只属于当前出牌者。
