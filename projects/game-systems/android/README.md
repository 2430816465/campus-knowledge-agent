# 冒险营地 Android 体验包

在项目根目录执行 `node android/pack-assets.mjs`，再进入 `android` 目录运行 `gradle assembleDebug`。产物为 `android/app/build/outputs/apk/debug/app-debug.apk`。Android 内部仅在手机回环地址启动资源服务，从 APK 内加载页面；四个游戏画面和单人存档不依赖桌面服务器。

双人房间需要另行运行 `server.mjs`，并让两台手机连接同一服务。首次进入《再闯一关》时填写服务器 WebSocket 地址，例如 `ws://192.168.1.20:4173/ws`，地址必须是手机可访问的局域网地址，不能使用手机自身的 `127.0.0.1`。桌面服务须以 `HOST=0.0.0.0` 启动，并在系统防火墙中允许对应端口。设置可在双人游戏首页重新打开。当前服务不具备公网账号、TLS 或正式生产部署能力。

在 Windows PowerShell 中，可先执行 `$env:HOST='0.0.0.0'`，再于项目目录执行 `npm start`；手机与电脑需位于可互通的网络。使用电脑的局域网 IPv4 地址填写 `ws://电脑IP:4173/ws`。

构建依赖：JDK 17、Android SDK Platform 36、Build Tools 35、Gradle 8.13 和 Android Gradle Plugin 8.13.2。调试 APK 使用 Android 默认调试签名，适合本机侧载体验；商店发行需要正式签名、隐私与平台 SDK 审核。
