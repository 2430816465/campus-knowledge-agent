# 再来亿把 1.23.0 · 再选一次

基于1.22.0当前源码，包名com.adventurecamp.game，版本码29。保留当前营地UI和其他九款游戏，同时纳入并行完成的营地文字对比度、成就图标和紧凑布局更新，包含打包前已完成的面包工坊隐藏设施点击修复。对应源码与APK一起交付。

## 御剑选路
- 再冲一阵更名再选一次，内部标识rush及已有存档键保持不变。
- 18关；前两关各4组选择，第3关6组，此后每关增加1组，第18关21组。第3关起每组提供3个不同选项，满编仍可选外侧光幕。
- 18位命名首领，按现有像素怪物资源增加主题配色、冠饰，组合扇形弹幕、冲锋、召唤、护甲、点射、震地和天劫攻击；不是18套全新绘制精灵。8类小怪：骨卒、疾行鬼、铁甲卫、赤咒师、再生妖、裂骨怪、冲阵兽、护魂巫。
- 新战斗以数字显示魔物剩余生命，归零击破。飞剑6阶，剑诀6阶，全队凡修、筑基、金丹、元婴、飞升5境；伤害、射速、穿透、追踪实际生效。飞升保留人物基础动作，增加披肩、光环及领队灵翼/仙冠。
- 更多光幕增益：疾风、破军、远游、雷鸣、赤炎、护盾、伙伴。雷鸣连锁与赤炎爆炸可同时生效。满阶光幕转化为6点护盾。

## 附属玩法：灵阵守点
- 营地准备页第二项，或游戏整备页切换进入。队伍固定守点自动御剑，点击战场左/中/右设置优先攻击区域；临近守线敌人仍优先处理。
- 30波，每5波首领。每波结束恢复8点灵阵和4点护盾，暂停提供4个未满级的不同机缘；无倒计时，无广告要求。
- 11种机缘，包括修复灵阵。敌人和弹幕越过守线扣除护盾/灵阵，灵阵归零失败。
- 闯关和守点独立存档、符晶与训练；守点保存最佳波次。本局成长不带入下次出发，符晶用于永久训练。
- 闯关首通每关8冒险币不变。守点不领取/占用闯关首通奖励；有效参与仍由营地统一记录。
