# 事实、推理与风险

冻结要求完全保留。本报告不构成放宽 P0 的批准。

## 事实（已核实）

- 当前目录原为空；用户 ZIP 仅含 CODEX_MASTER_PROMPT.md 与 docs/PRD_V1.0.md，两份已原样解压。用户本轮明确授权工程开发，PRD 旧状态未改写。
- ADB 实际输出无连接设备；用户确认暂不能连接。未核实所谓“红米 K80 游戏版”的真实厂商型号、系统和微信版本。
- Android 无障碍根节点接口读取当前活动窗口；通知监听收到应用实际发布的通知；MediaProjection 取得用户授权的屏幕/窗口像素，每个会话须重新取得授权。Android 应用沙箱隔离其他应用私有数据。
- 上游 goutoujunshi-jev-chat 的 Android README 与源码明确暂不支持微信，截屏入口对 `com.tencent.mm` 直接返回。它不证明所有机型绝对不可截屏，也不证明本项目可读微信后台。
- 三个仓库当前获取的 LICENSE 均为 MIT；Android 参考模块另有 NOTICE 的来源署名要求。Skill 是知识/流程文件，没有天然的独立在线服务接口。

官方依据：[AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)、[NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService)、[MediaProjection](https://developer.android.com/media/grow/media-projection)、[应用沙箱](https://source.android.com/docs/security/app-sandbox)。上游依据及固定 commit 见 UPSTREAM_RESEARCH.md。

## 推理（明确区分于实测）

当微信没有发布含消息正文的通知，消息会话也没有成为可观察窗口/像素时，上述公开接口没有该消息的正文信号。把这些渠道组合起来不能补出不存在的信号。可见节点/OCR 也无法凭昵称证明稳定联系人身份或跨全历史顺序。

因此，当前选定的普通授权架构不能承诺“后台无通知＋从未打开会话＋100% 零遗漏、零错人”。必须在指定机型留存可复现真值和原始采集日志；在获得新证据前，G1 状态为未通过/无法证实。这里是基于接口范围的架构判断，不是伪造的红米失败实测。

有限样本全部成功，只能证明对应版本与场景样本成功，不能证明永恒 100%。身份、方向或消息边界未知时必须计作未能证明正确，不能按正确匹配比例外推。

## 风险、成本与边界

| 项目 | 影响及处理 |
|---|---|
| 后台没有信号 | 核心 P0 阻断；不得进入 G2—G6 |
| 同昵称、改昵称、通知合并 | 无稳定 ID 时不自动关联，不能凭正文或昵称猜身份 |
| 快速连发/重复正文 | 保留原始每次观察；只有可靠原生消息 ID＋身份＋顺序一致才合并。未验证去重不是已完成去重 |
| OCR/黑屏/裁切 | 记录失败或未知；不绕过安全窗口；一行 OCR 不等同一条完整消息 |
| 进程终止/重启/撤权 | 记录可知断档及恢复时可能断档；不能保证杀死时仍有心跳，也不能自动证明补齐 |
| 多媒体 | 验证器仅保存可观察文本和媒体提示，不转写语音、不还原未暴露原图；关键内容验收仍未满足 |
| 独立真值与到达时刻 | 发送成功不自动等于在截止前到达；缺少独立到达依据或时钟校准则标为无法证实，不从收集到的数据反造 G |
| 测试原文 | 只允许授权测试会话；数据库正文 AES-GCM/Keystore；导出为明文，须专门保管、不得提交 Git |
| 证据完整性链 | 检测截断、顺序错误和未经重算的修改，不提供防伪身份签名；不能独立证明数据来自真实微信 |
| 采样成本 | 两秒 OCR、每次节点事件和详细证据耗 CPU、电量与磁盘；目前未测量，不能宣称适合长期运行 |
| Jev/API 费用 | G1 不调用云模型，后续 30—100 元/月仍待真实 token 计费；全量历史不可暗中缩减 |
| Skill 流程适配 | 恋爱大师禁止逐字代聊，且须明确启用视角。用户已明确要求本项目启用；产品后续须呈现用途与边界，仅用于分析，生成模型负责撰写 |

可以讨论但未经批准不会实施的选项：取得真正获得授权且有完整消息事件的官方数据源；明确调整收录范围；由用户改为导入/可见范围辅助。上述替代均不等价满足当前冻结 P0，不作为本项目默认路线。
