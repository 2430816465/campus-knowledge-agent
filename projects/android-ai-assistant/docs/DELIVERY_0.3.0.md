## 已实现行为

1. 首次在历史页复制或导入聊天，逐项校对身份、说话人、正文和从旧到新顺序。全部已确认历史、档案、原件及实际发送风格样本继续保留。
2. 在军师页为本次观众开启前台自动读取；微信前台页面、滚动或内容变化后，防抖并限频截图、本地中文OCR。切换档案、锁屏、撤权会暂停；不会后台读取隐藏消息或自动翻页。
3. OCR目前没有可靠的身份/消息边界/方向/最新状态提取器，全部走核对路径。可从读屏原文提取修正，或显式粘贴最新对方消息，每条单独填写、支持连发。
4. 核对确认后直接入库并自动调用已有完整分析链，无需再点生成。配置、云端授权、真实价格或费用条件不足时明确报错，已保存消息可回查；没有假候选和自动付费重试。
5. 每轮保存具体回复目标ID、版本和已核对原文，传给Jev、两个Skill及最终生成；全部可用历史仍进入上下文/全分块通读。报告展示本轮目标。
6. 同次读取重放拒绝入库及自动分析；不同次同文消息不自动合并。切换会话/档案、锁定和迟到结果有失效保护。候选始终由本人选择、编辑和手动发送。

## 操作与限制

安装和配置详见PRODUCT_INSTALL.md，交付为deliverables/xindong-junshi-debug.apk及xindong-junshi-source.zip，SHA256见同目录SHA256SUMS.txt。

核对并启动分析后先停留本App，完成后再回微信；微信页面/内容变化会保守取消旧轮，可能产生部分调用费用。可通过悬浮球在本人再次核对身份后加载已保存候选。新消息到来或历史/模型变化后须重新核对分析；旧报告仅供回查。
