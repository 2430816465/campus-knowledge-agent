## 一轮生成

1. 用户点击生成，或核对最新对方消息后自动启动（CR-20261013-04）；检查本地账户、当前观众、已确认材料、媒体原件引用、云端范围同意和组件用途确认。未核对OCR不调用AI。
2. 读取本观众全部已确认双向消息、档案、标签、事实、冲突及缺口。草稿 OCR 和未采纳候选不参与。
3. 使用本主播全部已确认且实际发送的文字/Emoji 统计长度分布、标点、语气、表情和连续分条习惯；当前观众可选择精选实例。其他观众原句不上传，仅提供同主播格式统计。
4. 容量足够时提交本观众完整原文；超限时逐块提交所有消息进行结构化记忆，必要时归并，并根据引用/问题回查原文。独立记录每块源 ID、输入 SHA 和返回模型。不能收敛或单段超限则停止，不删除早期历史继续调用。
5. 默认分别实际调用 Jev、狗头军师 Skill、恋爱大师 Skill，再由生成模型整合分歧并撰写候选。任一已启用组件失败则本轮失败，不静默切换为普通模型。
6. 严格解析报告 JSON、证据 ID 和候选；完整有效输出才允许选择。界面先显示候选，完整事实、推测、未知、分歧、理由、风险、下一步和组件原始分析可展开回查。
7. 用户编辑并逐条复制/参考，自行在微信输入发送。只有本人确认实际发送的最终文本才追加为风格学习样本。

最新消息模式先由LatestIntake核对并追加消息，再构建ReplyTarget。目标必须为本观众已确认消息的末尾，方向为对方且版本一致；每个开启组件和最终生成都收到目标原文，报告保存ID/版本。没有用整屏OCR最后一行猜测最新消息，也没有把新目标替换成全部上下文。核对不完整、同次观察已入库、过期/跨范围目标均拒绝；失败不自动重新提交付费分析，按既有429协议处理限流。

Jev 判断偏好支持均衡、稳妥、积极回应，是本应用传入 state 的决策偏好，不能当成供应商官方模型模式。拒绝、事实及休息边界始终优先；Jev 分值和候选自评分不是心理事实或质量验收分数。

## 上下文与长期记忆

风格统计保留标点次数、每条消息出现概率及按 Unicode 码点归一化的字符概率；连续发送组同时记录次数与分布。统计只取已确认的主播实际发送文字，空历史输出有限零值。表情计数采用注明范围的字符启发式，支持 BMP 心形，不把增补汉字误计为表情；不是完整 Unicode Emoji 词典。相邻发送组不推断未知的真实时间间隔。

coverage 记录 available/processed/sourceIds/recalledIds/chunks/mode/gaps。processed 表示实际提交处理的消息，不证明摘要保留了全部语义。全部微信记录是否取得始终由来源核对和缺口说明决定，不能从数据库行数推出完整。

小窗口辅助组件需要分块时，最终生成模型若仍可容纳全部原文，会恢复完整原文输入。超限模式的原文回查受模型容量限制，完整原件仍在本地。每轮记忆随报告加密保存；目前会重新通读当前全部材料，没有把旧摘要当唯一事实库，也没有未核验的跨轮缓存复用。

消息文字、导入文件和组件结果统一视为数据。系统指令要求拒绝其中的提示注入、编造经历和跨观众引用。引用 ID 越界会被程序拒绝；语义是否真实、是否充分利用历史仍需人工质量评审，不能由 JSON 合法性证明。

## 接口契约

生成接口支持用户配置的完整 HTTPS chat/completions 地址、模型名、Bearer Key、流式/非流式、JSON 模式，以及 max_tokens / max_completion_tokens 字段选择。不同供应商的其他协议、图片/音频端点和自定义鉴权尚无适配，不把“可切换”解释为任意 API 都已验证。

Jev 使用 [官方 systemone 协议](https://docs.typesafe.ai/api)：model/state/questions，noul/choice/score 输出。记录真实响应 model 与 usage，拒绝错误范围或不合法结构。默认别名不是固定模型快照。

HTTP 禁止重定向，连接超时 15 秒，读取超时 120 秒，响应文本上限 4M 字符。只对 429 最多再试两次，分别延迟约 1/2 秒；每次单独记账。网络中断、5xx、无用量不自动重试。流式片段只显示进度；截断/内容过滤及非法 JSON 拒绝采用。HTTP 正文和密钥不进入公共错误日志。

核心协议验证使用本机真实 HTTP 回环服务器及标识明确的响应夹具。它验证请求/解析/异常处理，不能当真实供应商连通或真实 AI 成功。

0.3.2对独立Skill增加明确JSON约定，优先于上游Markdown展示模板；facts/hypotheses须为带text和evidence_ids的对象数组，事实须有本观众真实消息引用，unknowns/risks/disagreements为字符串数组，strategy非空。空正文、JSON语法、字段与越界引用分别报错。失败诊断只含固定字段名、长度和内容SHA256，随本地加密审计保存；不记录被拒正文，不自动修补成成功或发起付费重试。

## 计费

以真实 usage × 用户核验的人民币单价计入微元台账；缓存输入单价单独处理，无缓存价格则按普通输入计价。价格链接、日期、汇率、上下文容量、输出容量须用户核对，模板不是已证实规格。

每次调用前持久化保守预留，初始月提醒额度 100 元；预留将达到额度时暂停，用户明确确认后增加 100 元。按上海时区月份计算。不降低历史范围、不关闭组件来省钱。

未知用量保持 UNCERTAIN 并阻断新调用；进程重启将残留 RESERVED 转为 UNCERTAIN。只有结束/中断的未知调用可由用户查账后结算，正在执行的请求不能改成零元。取消请求仍可能已产生费用。

手机与桌面各有本地账本，不能自动读取供应商完整账单。App 支持补录外部已核对账单增量；桌面对照首次账本使用配置 previousMonthMicroRmb 作为“本月已有费用”（历史字段名，不是上个月费用）。跨设备/跨月份需重新核对，不能重复相加供应商总额。100 元是提醒和调用前控制，不是绝不超额的结算保证。

UTF-8 字节数用于保守上下文/费用预估，不是服务商官方 tokenizer。P05和P05B累计4次真实推理均取得usage，手机TOKEN_ESTIMATE合计¥0.156426，其中本轮成功¥0.124052。供应商账单尚未核对，价格、缓存和计费变化可能影响实际扣款；没有月费实测，不能保证每日10—30轮必定只花30—100元。
