## 安装

APK：deliverables/xindong-junshi-debug.apk；SHA256 见 deliverables/SHA256SUMS.txt。源码：deliverables/xindong-junshi-source.zip。Debug 签名仅用于研发试用。

以后手机可用时，可复制 APK 到手机并通过系统安装器安装；允许该次安装来源即可。也可在本人完成 USB 调试授权后，用 `adb -s <你核对的设备序列号> install -r deliverables/xindong-junshi-debug.apk`。不要卸载旧产品来解决安装问题，卸载会丢失本机密钥和资料。G1 探针升级与产品是两个不同包，产品不会自动读取探针私有证据。

## 首次使用

1. 创建本地账户及至少 6 位口令，再创建主播、观众。即使同名也创建独立观众；每次核对当前微信身份。
2. 在“历史”导入授权文字、文件、多张截图或媒体。截图保留原件并本地 OCR；标题、时间、按钮可能被识别为正文，须跳过。
3. 逐条校对正文、说话人、时间和顺序；未知时间留空。核对本批身份与从旧到新顺序后“确认入库”。较早材料可上移；所有时间已核对时可按时间整理。重叠只是建议，不自动去重。
4. 图片、表情、语音、视频可查看/播放原件并保存完整描述/转写。无法识别的部分保留未知；目前没有自动语音识别或视频理解。预览超过 32 MiB 时导出完整原件核对，保存/导出不会按此容量截断。
5. 在“档案”补充备注、边界、历史缺口、标签与事实。矛盾保留两条记录，可添加处理说明。新观众无需先有标签。
6. 在“模型”配置生成接口和 Jev 接口、真实模型、密钥、窗口/输出容量、人民币输入/输出/缓存价格及依据。核对云端发送范围和组件说明，再保存。本机加密保存 Key；不要把 Key 发到聊天或提交 Git。
7. 返回“军师”，可主动点击“分析并生成候选”，或按下文核对最新消息后自动分析。默认 Jev、狗头军师、恋爱大师全部运行；配置缺失或任何组件失败会说明原因。没有配置真实 API 时不会展示假候选。
8. 选择候选后编辑各段，自行逐条复制/参考并在微信输入发送。实际发送的最终文本通过确认入口追加，未采纳草稿不会成为风格样本。

文字文件支持 UTF-8 纯文本、四列 TSV（时间、主播/观众、Kind、正文），以及 JSON 消息数组或 `{"messages":[...]}`。JSON 行需要 body，可含 speaker/time/kind；所有行仍需人工确认，不信任其中的原 ID、已校对标志或媒体引用。导出 ZIP 当前用于留存与回查，尚无整包恢复入口。

## 后续最新消息、前台自动读取与悬浮面板（有限实测，边界待验）

首次历史校对后，后续可直接在“军师 → 最新消息 → 回复建议”粘贴对方最新原文，每条单独填写。连续多条按旧到新添加；多行正文仍放同一个输入框。核对三个选项后点“确认最新消息并自动分析”，消息入库并启动完整分析链；无需额外点击生成。没有截图时也可使用此入口。

需要前台自动读取时，在App选择当前主播/观众，点“授权前台读取”，由本人在系统无障碍设置开启“心动军师”。回军师页开启“本次档案开启微信前台自动读取”，进入对应的已授权微信聊天，等待约3秒且页面保持不动。可见页面/滚动/内容变化会触发本地采样；不是后台收信或历史全收。军师悬浮球中也可开启/暂停，或“点击读取当前可见屏幕”重读。

取得预览后由本人点悬浮球 → “核对最新消息并分析”（菜单可滚动）。0.3.1让操作菜单在自动采样时保持显示，候选失效仍撤掉；红米P02B已验证菜单保持及直接核对交接，OCR仍有错字，长时稳定性待。为保留本次预览，测试时使用该按钮直接进入核对页；最近任务可能经过其他应用，触发隔离清除。整屏OCR可能有错字、双方原文、标题和按钮，本版不能可靠自动区分，全部须人工核对。将最新尚未回复且未入库的对方消息提取/修正到输入框，确认当前观众、原文方向和新发生状态，再提交；不要把整屏原文直接填入。也可把整屏加入普通待校对批次作为历史。未知消息时间保持空，不以截图时间代替。

确认后先停留本App等待分析完成；返回微信、滚动或内容变化会保守取消旧任务，部分调用可能已收费，不会自动重试。若需在微信查看已保存候选，先本人核对聊天身份，再选“我确认当前聊天对应此档案，加载已保存候选”；档案/配置变化会拒绝旧候选。面板逐条复制，不自动粘贴或发送。

同次读取确认后不能再入库或自动调用；相同文字的新一次真实发送须本人确认。识别失败可粘贴；没有正文的图片/语音等仍走历史页媒体原件及描述校对流程，不把占位符当完整语义。切换档案、锁屏、撤权后自动读取会暂停，恢复时重新开启。每轮报告展示具体回复目标和全部已提供历史覆盖范围。

系统拒绝截图、页面变化或撤权时应显示原因并清除旧结果。P02B采样/菜单/交接、P04R核对新消息和P05B候选/报告已有限实测；锁屏、撤权/恢复、候选悬浮面板及HyperOS长期策略仍待指定红米补验，探针结果不能代替产品验收。

## 费用、删除、导出

“费用”显示当前主播明细及本设备本月总计/预留。达到初始 100 元提醒额度前会暂停，需本人确认增加额度。未知用量须先查供应商账单；其他设备费用可补录尚未计入的本月增量，防止重复计账。

导出包含本观众原件、聊天、来源和分析报告的明文 ZIP，密钥不导出。选自己的保存位置并妥善保管。删除观众/账户有确认框；已导出文件需本人管理。卸载及设备密钥丢失均可能导致无法恢复，当前没有云同步或自动备份恢复。

导出过程中如出现失败，所选位置可能留有不完整ZIP；请删除该失败文件并重试，以App明确成功提示为准。

## 构建与不连接手机的测试

在工程根目录运行（PowerShell 7、JDK17、SDK36/BuildTools35）：

```powershell
python scripts/verify_baseline.py
python -m unittest discover -s scripts/tests -v
.\scripts\Build-Product.ps1
.\scripts\Test-ProductEmulator.ps1 -Serial emulator-5580
python scripts/package_delivery.py
```

模拟器必须自行启动，脚本只接受 emulator- 开头且系统属性确认是模拟器的指定序列号；不会选择真实手机。首次构建需要联网下载固定依赖。脚本可指定 -JavaHome/-SdkRoot；测试只使用明确标识的合成数据。

真实接口与 100 组盲评步骤见 AI_QUALITY_TEST_REPORT.md。工程测试、模拟器通过、真实微信通过和 AI 可用率是不同验收层级。
