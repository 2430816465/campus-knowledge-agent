# 产品工程架构

2026-10-13，0.3.0-development。依据原冻结基线和 CR-20261012-01/02、CR-20261013-04；真机暂缓期间允许继续独立研发，不表示 G1 已通过。

## 工程边界

| 模块 | 职责 |
|---|---|
| app / probe-core | 独立 G1 探针及证据规则；保留旧后台失败和点击读取实测记录 |
| product-app | 原生 Kotlin/Compose 产品研发版：账户、历史校对、档案、候选、报告、模型、费用、主动读屏 |
| product-core | 不依赖 Android 的历史模型、范围校验、风格统计、上下文、AI 编排、HTTP、计费及加密格式 |
| qa-runner | 桌面真实接口对照实验；与产品复用同一 AI 引擎，不提供假模型运行选项 |
| qa / scripts | 100 组合成输入、离线盲评、严格评分审计、构建、证据核验与交付打包 |

UI → ProductController → Vault / AnalysisEngine。文件和仓库操作使用单独 IO 执行器；模型调用使用独立执行器，结果交回主线程更新界面。主动读屏的部分位图转换仍在主线程，指定手机上的延迟、内存与流畅性尚待实测。Application 持有会话，旋转不重新提交付费任务；进程重建后账户处于锁定状态。

## 数据与隔离

Scope = Account ID / Streamer ID / Contact ID，三者为稳定随机 ID；昵称仅显示。同名观众不会合并。消息、证据、媒体、标签、事实、冲突、批次、模型配置和分析记录均按所属范围保存和验证。

底层为 SQLite，业务记录使用 AES-256-GCM 加密 JSON；密钥由 Android Keystore 保存，AAD 绑定记录类型、范围和 ID。原始媒体采用分块认证加密，每块最多 1 MiB；结束记录验证总块数、长度和 SHA256，截断、调换、跨档案解密及尾随数据均拒绝。小记录及早期产品媒体格式仍可读取。缺少设备密钥时保留旧记录并报错，不生成新密钥覆盖旧仓库。

本地账户口令使用随机盐和 PBKDF2 校验，并限制连续失败尝试。它是应用内账户解锁机制；不是每位主播单独的硬件密钥，也不能宣称抵抗已控制系统的攻击者。当前账户目录与本机密钥共同管理多个逻辑账户。

首次历史导入必须先进入草稿批次，核对身份、方向、正文、时间及顺序后才成为正式消息。截图原件、原始文字、SHA、校正前版本均保留；跳过重叠须本人确认，程序不自动删除同文消息。未知时间允许留空，绝不补造时间。批次可保存进度、重排、合并、跳过，已提交批次禁止重复提交。

后续LatestReview由用户核对最新对方消息、身份、尚未回复及新发生状态，LatestIntake追加REVIEWED_LATEST证据与消息；原始读屏/PNG、修正原文及核对标志保留。同次scope+observation ID稳定生成证据ID，重启后仍拒绝重放；不同观察的相同正文不合并。ReplyTarget校验尾部消息ID、版本与方向，后续新消息/已发送内容/修改令目标失效；每个开启的组件和报告均保存明确目标，不以最近消息替代全部上下文。

标签由用户手动设置或确认 AI 建议；事实保留来源消息，矛盾同时保存旧/新记录与处理说明。原件按观众目录保存；保存完成或重新解锁时清理无引用的加密临时文件。删除观众/账户同时清理其媒体与报告；设备总费用台账保留，避免删档后重置预算。

## 主动读取与候选

产品由本次档案开关启用前台自动采样，或在用户点击时，通过已授权 AccessibilityService 截取当前可见微信窗口并本地中文OCR。前台窗口进入及微信页面/滚动/内容事件防抖1秒，采样间隔至少3秒；同文预览沿用观察ID，已消费观察不自动上传。Android 14+ 使用窗口截图 API，较早版本使用显示截图 API。读取前后核对包名、窗口、屏幕锁定状态、请求 ID、导航计数和档案；结果仍是待校对材料，当前没有已验证的自动最新消息解析器。

所有OCR须在App核对后自动调用完整分析链；可显式粘贴作为替代。进入本App可保留预览，离开到其他应用清除；回到微信按新窗口变化保守失效。自动模式为会话内状态，不随进程重启恢复，档案切换/锁屏/撤权暂停。屏幕内容变化取消付费旧轮，用户须在App等待完成；这种保守取消策略的误取消率与耗电待真机验证。

产品不申请通知监听，不承诺隐藏消息/屏外内容。无障碍浮层提供悬浮球、底部候选面板和打开 App 入口。没有发送、点击微信控件、填写输入框或自动粘贴路径；复制只写入系统剪贴板，用户自行操作微信。

切换档案、修改材料/模型、锁定账户、收到导航或滚动事件时，取消旧任务并清除旧候选。所有异步结果检查范围与版本，锁定后排队任务不能重新打开旧账户。加载保存候选还须本人确认当前聊天，并核对当前历史、配置、风格样本指纹；过期资料只能回查。微信同窗口内的全部导航能否被观察到仍需真机验证，不能宣称绝无串人风险。

## 权限、恢复及容量

产品需要 INTERNET 才能调用用户配置的 HTTPS 服务；无障碍由本人在系统设置授权。无需联系人、录音、全盘文件或普通悬浮窗权限；文件通过系统文件选择器授权。关闭云备份/设备迁移，避免密文离开原设备后失去 Keystore 密钥。Debug APK 用于研发测试，正式签名、发布渠道及升级迁移尚未验收。

文字文件要求 UTF-8，单次最多 16 MiB，超限/错误编码拒绝且不截断。截图识别时缩放最长边至不超过 2560 像素，原件不缩放。媒体导入/导出采用流式加密，容量受存储空间限制；App 内原图/音视频预览最多解密 32 MiB，超限需导出原件查看。不是完整历史保存上限。

当前每个观众的结构化记录整体保存为加密 JSON；已对 1000 条上下文构造运行测试，未来持续增长时数据库写入、内存、耗电和延迟仍须实测。尚无云同步、iOS 客户端、自动语音转写/视频语义识别或 ZIP 备份恢复入口。媒体可人工完整转写/描述后参与分析，未知部分明确保留。

## 可复现与证据

`scripts/Build-Product.ps1` 运行核心测试、桌面工具编译、Android lint 和 APK 构建。仪器测试必须明确选择模拟器；真实手机与微信验证独立记录。锁文件固定解析依赖；源包排除密钥、真实聊天、原始手机证据、构建缓存和上游整仓库。

相关实现：product-app 的 Vault.kt、ProductController.kt、ChatReadService.kt、MainActivity.kt、MediaReview.kt；product-core 的 History.kt、SealedBox.kt、Analysis.kt、StyleAndContext.kt、HttpGateway.kt、AiModels.kt。
